# Random New World 1.1.0

Generate a new world for Europa Universalis V while keeping the Old World vanilla.
Explore it from Europe or start as one of its native countries.

## What is new

- **A new generator window.** The window is rebuilt on the system web view (Tauri) with a
  sharper map viewer: population, climate, terrain and area lenses, borders that stay crisp at
  any zoom, and a window that stays responsive while game inputs are compared. The classic Qt
  window remains as the fallback and can be chosen in Settings or with `--classic`.
- **The Wall.** A sixth landmass archetype: a straight north-south continent or island chain
  with a mountain spine, from 4% to 44% of the canvas wide. It takes its land first and leaves
  the rest to the continents beside it.
- **More control.** Resource frequency sliders, the upper peasant share, a target of up to 60%
  of inhabited land in native states, and a control that keeps the New World's land away from the
  Old World's shores.
- **Better geography.** Coasts, water bodies and drainage are drawn together; mountains and hills
  are continuous ranges; vegetation follows climate; sea locations and their crossings are cut
  like ordinary seas; ocean currents are clear courses or none; land keeps away from the polar
  edges; small islands no longer sit in a dark or light disc.
- **More varied natives.** Native states keep stronger primary-culture and faith cores and
  take less uniform outlines. Connected territories, capitals and farming rules still hold.

The [changelog](../../CHANGELOG.md) describes each change in detail.

## Compatibility

Targets **EU5 1.4.6, Steam build 26300913**. Across the Pillars is optional; its fixed New World
geographic references are adapted to generated worlds. Start a new 1337 campaign with one world
mod enabled, and retain that mod for its saves. Existing generated worlds and saves are not
rewritten or migrated.

Algorithm epoch **60** replaces epoch 59: the world bytes changed, so a World Code made by 1.0.0
can give another world in 1.1.0, and the application says so. Keep a built world that saves use.

Windows and Linux/Proton are the intended delivery paths. Windows binaries are unsigned; Smart
App Control may block the generator. The Proton prefix of EU5 has no WebView2, so the hub run
through Proton opens the classic window. Other mod combinations and multiplayer are unverified.

## Packages

- **Windows:** standalone generator archive.
- **Workshop-Windows-Proton:** hub folder with the generator; upload this hub,
  never a generated world. Linux/Proton players use the same Windows generator.
- **Linux:** native application archive.
- **Source:** project source archive under MPL-2.0.

Verify the archives against `SHA256SUMS`. These packages include no game assets;
world mods are generated locally from the player’s installation.
See the [generator guide](../generator-guide.md) and [known limitations](../known-limitations.md)
for setup, save handling and the scope of verification.

## Windows binary scans

VirusTotal analysis covers the exact Windows binaries built from the candidate
commit recorded in `BUILD-INFO.json`. That hand-off manifest carries each
binary's size, SHA-256, report link and engine results. Reports apply only to
their exact files. Timeouts and engine failures are unknown, not clean results;
the scans do not cover archives or every dependency and do not provide a
signature or guarantee acceptance by Windows security features.
