# Random New World 1.2.2

This release brings smoother drawn coasts, a unified land editor and lower memory use. It targets **EU5 1.4.7 / Steam build 26377361** and uses algorithm epoch **63**.

## What changed

- Cut subcontinents through narrow parts of the land instead of along straight rows. Islands and peninsulas stay together, and South America keeps more of its share in worlds with several land arms.
- Drawn land now stretches smoothly onto the map. **Land editor…** brings sketches, images, templates and terrain painting together, with starting maps for Westeros, Tamriel, Kalimdor and Ansalon.
- Generation asks for about **8 GB of free RAM**, down from 9 GB. The final map check reads the export in strips; the reference world remains byte for byte identical.
- **Experimental features** in Settings reveals the **Algorithm epoch** choice: epoch 63, 62 (1.2.1) or 61 (1.2.0). It is off by default.
- Remove the duplicate **Terra Incognita** control from Settings; the choice remains on the **World** tab.

## Compatibility and existing worlds

Generate a new world to get the new subcontinent layout and smooth drawn coasts. A world code from 1.2.1 (epoch 62) can make a different world under the default epoch 63. Turn on **Experimental features** and choose epoch 62 to use the earlier algorithm on the same game files. Existing world mods and saves keep their files; updating the generator does not rewrite or migrate them.

Use the exact EU5 version that made a campaign's map. Enable one generated RNW world at a time and restart EU5 before switching maps.

## Downloads and help

- **Windows:** standalone generator archive.
- **Workshop-Windows-Proton:** generator hub for Workshop and Linux/Proton use.
- **Linux:** native application archive.
- **Source:** project source under MPL-2.0.

Verify downloads against the attached `SHA256SUMS`. These packages contain no game assets; worlds are generated locally from your EU5 installation. The macOS archive is a CI build, not an offered game route.
