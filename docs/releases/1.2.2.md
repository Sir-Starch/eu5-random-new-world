# Random New World 1.2.2

This release improves the land editor and reduces the memory needed to generate a world. It targets **EU5 1.4.7 / Steam build 26377361** and uses algorithm epoch **63**.

## What changed

- Cut subcontinents through narrow parts of the land instead of along a straight row. Islands and peninsulas stay whole, and South America keeps more of its share in worlds with multiple land arms.
- Drawn lands now stretch smoothly onto the map. The **Land editor…** brings sketching, images, templates and terrain painting together, with starting maps for Westeros, Tamriel, Kalimdor and Ansalon.
- Ask for about **8 GB of free RAM**, down from 9 GB. The final map check now reads the export in strips; a reference world remains byte for byte identical.
- Add **Experimental features** to Settings. It reveals the **Algorithm epoch** choice, which can make worlds using epoch 63, 62 (1.2.1) or 61 (1.2.0). It is off by default.
- Remove the duplicate **Terra Incognita** control from Settings; the choice remains on the **World** tab.

## Compatibility and existing worlds

Generate a new world to get the new subcontinent layout and smooth drawn coasts. A world code from 1.2.1 (epoch 62) can make a different world under the default epoch 63. Turn on **Experimental features** and choose epoch 62 to reproduce the earlier algorithm on the same game files. Existing world mods and saves keep their files; updating the generator does not rewrite or migrate them.

Use the exact EU5 version that made a campaign's map. Enable one generated RNW world at a time and restart EU5 before switching maps.
