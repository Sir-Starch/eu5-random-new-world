# Random New World 1.0.0

Generate a new world for Europa Universalis V while keeping the Old World vanilla.
Explore it from Europe or start as one of its native countries.

- Five landmass archetypes, adjustable geography and an optional larger ocean canvas.
- Procedural relief, climates, rivers, coastal waters, sea lanes and currents.
- Native countries, cultures, religions and subject networks, with optional great
  empires and other extraordinary societies.
- Regional stories, formable countries, colonial names and adapted American content.
- A desktop generator with a world library, atlas, shared World Codes and rerolls
  of peoples or resources. All eleven official EU5 languages are included.

## Compatibility

Targets **EU5 1.4.5, Steam build 26211608**. Across the Pillars is optional;
its fixed New World geographic references are adapted to generated worlds.
Start a new 1337 campaign with one world mod enabled, and retain that mod for
its saves. Existing generated worlds and saves are not rewritten or migrated.
Algorithm epoch **59** is retained from 0.13.22.

Windows and Linux/Proton are the intended delivery paths. Windows binaries are
unsigned; Smart App Control may block the generator. Other mod combinations and multiplayer are unverified.

## Packages

- **Windows:** standalone generator archive.
- **Workshop-Windows-Proton:** hub folder with the generator; upload this hub,
  never a generated world. Linux/Proton players use the same Windows generator.
- **Linux:** native application archive.
- **Source:** project source archive under MPL-2.0.

Verify the archives against `SHA256SUMS`. These packages include no game assets;
world mods are generated locally from the player’s installation.
See the [generator guide](../generator-guide.md) and [known limitations](../known-limitations.md)
for setup, save handling and the scope of verification.
