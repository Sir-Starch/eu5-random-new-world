# Dependency-aware roadmap

All engine validation gates target the currently detected EU5 build, then repeat on future patches. The only in-game result so far is metadata recognition; the owner requested no more game launches in this session [V-GAME C11–C12]. The D0 T2 mod candidate and T3-capable world model exist offline under the [implementation contract](implementation-contract.md) and [ADR 0002](adr/0002-d0-generator-stack.md); in-game acceptance remains pending. “Opus design/implement” needs architecture and production work; “Sonnet implementable” is bounded work. See [backlog](handoff/sonnet-5.5-backlog.md).

| U1. Player experience and setup | Opus design, then Sonnet | Owner requirement of 2026-10-20; depends on R8. Delivery is decided in [ADR 0004](adr/0004-generator-application.md): a local application with a window generates the world, and the game takes it up without being closed. The application: game and profile discovery; presets, continent type and the [product spec](product-spec.md) controls; a seed that is random by default and can be copied, pasted, saved and reused with its settings; a preview; generation with progress per stage and a cancel button, so nothing looks frozen; validation and in-place installation; never a terminal. In the game: options the engine applies at start as game rules of the mod [V-LOCAL C81], among them visibility modes from a New World visible at the start to one hidden by terra incognita already at country selection (optional, as in EU4's random New World according to the owner), and the seed shown in game. Premises: playsets switch and every new game mounts the mod's map data inside the running game [V-GAME C82; V-LOCAL C83]; the game cannot compute a geography itself (C83); whether a mod rewritten on disk is re-read is experiment 013; a main-menu button that opens the application is a lead (`OpenURL` exists in the GUI, C83); whether the country-selection map can hide the New World is [UNKNOWN]. Gate: owner review of the application on Windows and Linux, of every visibility mode at country selection and in the campaign, of a seed reused from game to application and back, and of a reroll (generate, new game) that never closes the game, or with one announced restart if experiment 013 requires it. |

Alternatives at R2: **T3** gives maximum topology freedom but requires new-ID support and broad setup rewriting; **T2** preserves IDs but limits geography count and may still demand full visual regeneration; **T1.5** reclassifies existing cells and may give meaningful coastlines with less ID coupling; **T1** is an attribute-only research fallback. None is asserted to work in 1.4.1 [UNKNOWN C13]. Runtime T5 is parked unless a supported engine API and live test appear.
