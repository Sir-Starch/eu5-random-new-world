## Random New World

Europa Universalis V の新世界ジェネレーターです。南北アメリカを一から作り直します。大陸、海岸、起伏、気候、河川、植生、資源、州、そして先住民。旧世界は Paradox が作ったままに残します。**作られた世界は一つひとつが完全なマップMODです。** 単体で遊べます。世界はいくつでも保存でき、削除も、ワールドコードの共有もできます。遊ぶのにこのジェネレーターは要りません。同じバージョンのゲームを持つ人なら、だれでもコードから同じ世界を作れます。

このアイテムはプレイセットで有効にする必要はありません。中身はジェネレーターだけです。

## このアイテムにプログラムが入っている理由

EU5 は MOD を読み込むとき、ファイルからマップを組み立てます。MOD はデータであり、コードは実行できません。ゲームのスクリプトは開始時にどこをだれが持つかは決められても、陸地や山脈や川を作ることはできません。EU5 にはゲームにコードを加える公式の方法がありません。

そこで、このアイテムに同梱された小さなプログラムが世界を作ります。お使いの EU5 のインストールを読み取り、世界を作り、普通の MOD として保存します。ゲームを書き換えることも、ゲームに接続することも、ゲームの中で動くこともありません。Paradox の利用規約は、プレイヤーが無料で作成・共有できるコンテンツにプログラムを含めています。

## 使い方

1. **MOD** ウィンドウで Random New World の **フォルダで開く** を押し、**Random New World Generator** をダブルクリックします。
2. 世界の種類を選びます。超大陸、大陸、小大陸、群島、散らばる島々の五つです。シードはランダムのままでも、自分で入力しても、ワールドコードを貼り付けてもかまいません。**基本** では、EU4 のランダム新世界と同じように、おなじみの質問に一言で答えます。陸地の広さ、先住民の民族と国家の数、先住民の大帝国が興る頻度(なし、まれ、時々、よく)、金と銀の豊かさです。**カスタマイズ** ではすべての値を変えられます。陸地、海岸、マップの縮尺、そして大帝国から孤立した国家までの先住民。示される値はどれを選んでも遊べる世界になります。
3. **作成** を押します。2、3 分で世界が新しい MOD として MOD 一覧に加わり、「RNW: Small continents 7K3Q」のような名前(世界の種類とタグ)が付きます。名前はジェネレーターで変えられます。新世界が隠れている間は、MOD 一覧の画像に同じタグが赤で入るので、世界を見分けられます。
4. ゲーム内でその世界にチェックを入れ(一度に一つの世界だけ)、新しいゲームを始めます。EU5 を起動してからすでにキャンペーンを遊んだ場合は、先に EU5 を再起動してください。何をすればよいかはジェネレーターが教えてくれます。

ジェネレーターは作った世界をすべてコード付きで保存します。**設定** で表示を選ばない限り、新世界は遊ぶまでどこでも未知の土地のままです。ジェネレーターの画像でも、ゲームの MOD 一覧でも、新しいゲームの画面のマップでも同じです。設定一つでこれをすべてオフにできます。ワールドコードは、同じバージョンのゲームがあるどのコンピューターでも、同じ世界を 1 バイトたがわず再現します。

ジェネレーターはゲームのすべての言語に対応し、Steam が EU5 を起動する言語で立ち上がります。

## このプログラムがすること、しないこと

- EU5 のインストールを読み取り、書き込むのは二か所だけです。作った世界の MOD(ドキュメント内の EU5 フォルダの `mod/rnw_world_…`)と、自分のデータフォルダです。
- ネットワークを使わず、管理者権限も求めず、レジストリにも触れず、ゲームのファイルを一つも変更しません。
- ソースコードは Mozilla Public License 2.0 で公開しています: https://github.com/Sir-Starch/eu5-random-new-world。各リリースはタグ付きのコミットから自動でビルドされ、全ファイルの SHA-256 チェックサムもそこで公開しています。
- プログラムを信頼するかどうかはあなたが決めることです。コードを読むことも、チェックサムを照合することも、自分でビルドすることもできます。

## Windows の警告

- Steam がダウンロードしたファイルにはインターネット由来の印が付かないため、Windows SmartScreen の確認は出ないはずです。[Confirm in 020.]
- ウイルス対策ソフトは、まだ知らない新しいプログラムに警告を出すことがあります。各リリースのページには VirusTotal のスキャン結果へのリンクがあります。
- Windows 11 のスマート アプリ コントロールは既知の署名がないプログラムをブロックし、個別のプログラムを例外にする方法はありません。[Until signed:] ジェネレーターはまだ署名されていないため、スマート アプリ コントロールが有効だと起動しません。[Once signed:] ジェネレーターとそのネイティブモジュールには [signer] の署名があります。

## Linux と Steam Deck

ゲームは Proton で動きます。この場合「フォルダで開く」は Wine のファイルエクスプローラーを開き、同じジェネレーターがそこで、ゲーム自身の Proton プレフィックスの中で動きます。何もインストールする必要はありません。[Steam Deck: confirm.]

## 制限

- **新しいキャンペーンのみ。** 世界はキャンペーンを始める前に作る必要があります。
- **遊ぶ前に作るか、再起動を。** 同じセッションでキャンペーンの後に別の世界を始めると EU5 がクラッシュします(ゲームエンジン側の不具合です)。EU5 を起動してすぐに作るなら再起動は不要です。キャンペーンの後は、新しい世界の前に EU5 を再起動してください。
- **ゲームのアップデート。** EU5 のアップデート後、新しいビルドに対応するまでジェネレーターが動かないことがあります。対応後は世界の作り直しを提案します。古いセーブには、そのとき遊んだ世界が必要です。コードからもう一度作ってください。
- **一度に一つの世界。** プレイセットでは作った世界を一つだけチェックしてください。
- **マルチプレイ。** 全員が同じワールドコードと同じバージョンのゲームを使います。
- **メモリ。** 2 分間の生成に約 7.5 GB の空きメモリが要ります。EU5 の推奨環境の 32 GB なら十分です。
- **実績。** ゲームを変える他の MOD と同じく、ゲームのチェックサムが変わります。[Confirm what EU5 allows.]

## 削除

ジェネレーターで世界を削除する(**ワールドを削除**)か、フォルダを自分で消してから、サブスクライブを解除してください。残した世界はジェネレーターがなくても遊べます。
