# ADR 0008: Worlds are Workshop mods; the generator is our factory

**Status:** Accepted 2026-10-21 (owner direction). Supersedes the delivery decision of [ADR 0004](0004-generator-application.md); [ADR 0007](0007-application-window-and-packaging.md) stays on hold.

## Context

The owner asked on 2026-10-20 that the player does everything in the game's menus, keeps no separate generator on disk and runs nothing from a terminal, and that the finished mod is published on the Steam Workshop. On 2026-10-21 the owner objected to a separate generator program (the window of ADR 0007) and asked how a mod that is not inside the game could be published on the Workshop.

The facts that bound the choice [INFERRED from C83, V-LOCAL 1.4.2]: `eu5.exe` has no map generator (its `CMapGenerator` reads `locations.png`), a mod is a folder of data that the game mounts and never executes, and script effects change the start state (countries, pops, owners, cultures, religions) but not land, sea or relief. A Workshop item is such a folder. I found no Paradox rule that bans executables in a Workshop item ([User Agreement](https://legal.paradoxplaza.com/eula), searched 2026-10-21), but the game launches nothing from a mod, so a program in an item would have to be found and started by hand outside the game, which is the experience the owner rejected.

## Decision

1. **The product is Workshop mods only.** A player subscribes, enables a world in the playset (the game's own mod menu, which reloads mods without closing the game [V-GAME C82, C88]) and sets options on the new-game screen as game rules [V-LOCAL C81]. Nothing else is installed.
2. **Structure.** One base mod with the game rules and everything shared between worlds, and one mod per world that lists the base in its metadata `relationships`. Whether the shared part can be split from the per-world part (the vegetation instance files are 763 MB of the 1,286 MB of a world and mostly copy the Old World) is to be tested offline and in the game [UNKNOWN].
3. **A finite pool of curated worlds,** generated by us, each checked offline and in the game before it is published. Variety beyond the pool comes from societies rerolled by script at the start of a campaign (cultures, religions, states, borders), which is investigated as its own piece of work [UNKNOWN].
4. **The generator stays,** as the factory that makes and checks the worlds and as an open-source tool for people who want a seed of their own. The game never needs it, and no work on a player-facing window continues.
5. **Publication needs the owner's legal decision** on distributing mod files derived from vanilla rasters, decals and instance files ([legal](../legal.md)).

## Consequences

R9 (packaging for players) and U1 (setup application) are replaced by: the base mod with game rules, the world packs, size reduction, and the in-game setup of visibility modes. The seed is a property of a published world, shown in its name and description; infinite seeds are not offered in the game. The headless core, discovery, world codes, installation and the PyInstaller folder stay in the repository as tools.
