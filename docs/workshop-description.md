# Workshop description

The Steam Workshop text for release 1.0.0 ([ADR 0009](adr/0009-hub-mod-with-generator.md)) is kept in Steam's own markup, ready to paste: [`workshop/english.bbcode`](workshop/english.bbcode) and one file per official language in [`workshop/`](workshop/). It covers what players get, four steps to create and enable a world, DLC support, requirements and campaign compatibility. The Linux / Proton guide image is embedded in every language. Guides, downloads, known issues, bug reports and technical details are linked on GitHub. The licence and unofficial-project notice occupy one short footer.

Rules for the text:

- **Every statement holds for the published build.** Verify the supported game version and features against the candidate before upload ([release process](release-process.md)). Keep internal acceptance notes in the repository, outside the player-facing text. Across the Pillars wording follows the [compatibility audit](research/compatibility-1-4-5.md); save, other-mod and multiplayer wording follows [known limitations](known-limitations.md).
- **Write for players.** Lead with exploration, native countries and campaign choices. Explain the separate generator through the launch steps. Put implementation, licensing details and verification records on GitHub. Describe compatibility limits directly; do not promise that regenerating after an update preserves saves.
- **Steam's markup only**: `[h1]`, `[h2]`, `[b]`, `[i]`, `[list]`, `[olist]`, `[*]`, `[quote]`, `[url=…]`, `[img]`. Section headings carry one emoji each; Steam shows them as text.
- **8,000 bytes of UTF-8** per description, the closing NUL included ([Steamworks: ISteamRemoteStorage](https://partner.steamgames.com/doc/api/isteamremotestorage), `k_cchPublishedDocumentDescriptionMax`, accessed 2026-10-24). Cyrillic takes two bytes a letter and CJK three, so the Russian text is the tightest: it says the same as the English in fewer words.
- **The window's words for its controls and the game's for its interface** in every language (§2.9 of [localization](localization.md)): *Создать*, *Grundlagen*, *Condição de Jogo*, *播放集*, the game's name of Ironman. The mod list's titles stay English (C276), so the example name does too.
- **Translations follow the English.** Each translation starts with a line `source: <fingerprint>` naming the English it was made from; that line is ours and is not pasted. Change the English, then every translation, then the fingerprints. `tests/test_workshop.py` fails on a missing or outdated translation, on markup or links that differ from the English, on a lost note and on a text over the limit.
