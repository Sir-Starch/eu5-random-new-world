# 022 — What the new-game screen lets a mod do: a rule, a log line and terra incognita

- **Status:** **PARTIAL.** Prepared 2026-10-21 (generator 0.9.15). First run by the owner 2026-10-21 14:52-15:02 (C129): hypotheses 1-3 hold (the rule is listed, scripts read it, `debug_log` works), and TI covers nothing at selection; the reaction of the lobby's list to the filter and of the map to clicks is still open.
- **Cleaned up 2026-10-22:** the probe mod's source (`rnw_exp_probe_lobby/`, 5 files) and its test were deleted once the cover worked (experiment 023, run 5, C139): its game rule only showed a setting that did nothing on the Game Rules tab. This record keeps what it did; the installed copy is removed from the profile as INSTALLED says.
- **Why:** The owner wants the New World hidden by the game's own terra incognita (TI) already at country selection, whatever the map lens, with no way to start on it (as EU4's *Terra incognita in lobby*, C122), as an option that is on by default and can be switched on the new-game screen itself. Reading the game's files shows what the first half of that needs and what it lacks (C123, C124):
  - **There is a place for the switch.** The new-game screen is the lobby; its right panel has a Game Rules tab that lists every rule of `main_menu/common/game_rules/`, so a mod's rule needs no GUI change [V-LOCAL; that a mod's file is read like vanilla's is INFERRED].
  - **TI is the engine's own and works from a viewer.** `CTerraIncognitaManager` fills the visibility texture from the *viewing country*: a forced observed country, else the local player's. With none, everything counts as known. At selection there is no player country yet, so nothing is covered (C127). The owner confirmed that the New World is not hidden at selection and pointed out that the map is drawn identically in the lobby and in the game, so the same TI applies once the lobby has a viewer. Whether the country clicked in the lobby becomes that viewer is [UNKNOWN] (the lobby keeps `GetPlayerOrLobbyCountry` apart from the player).
  - **The list of countries can be thinned by data.** Lists have data-driven filters (`in_game/gui/filters`) that a mod may add, on by default, reading a game rule (C128). Whether that reaches the lobby's list is [UNKNOWN].
- **Hypotheses:** (1) A rule from a mod is listed on the lobby's Game Rules tab with its texts. (2) A script reads the chosen setting with `has_game_rule` after the lobby, and two hooks (`on_game_start` extended from a second file, `on_game_started_after_lobby`) run. (3) `debug_log` reaches `debug.log`. (4) The lobby map covers the New World with TI in some state (nothing chosen, an Old World country, a New World country) or covers nothing; the reading of the engine says nothing when no country is chosen. (5) A country filter without a tag, on at the start, is applied to the lobby's list of countries (with the rule on Hidden only countries whose capital is outside America remain) and can be unticked; on Shown the list is whole.
- **The probe** (`rnw_exp_probe_lobby/`, our own text, 5 files): a rule `RNW probe: New World` with the settings Hidden (default) and Shown, which change nothing in the game by themselves; the two hooks that only write `RNW probe: …` lines (the rule's value, and whether a human country exists after the lobby) with `debug_log`; a country filter `RNW probe: outside America` (on at the start, reads the rule); the English texts. No map, no setup, no file of the game. If you installed the first version (4 files), install it again with `--replace` (game closed).

  3. Open the Game Rules tab of the right panel: is *RNW probe: New World* listed, on which tab (General, Multiplayer, Flavor), with the texts Hidden/Shown? Change it to Shown and back to Hidden.
  4. Click an Old World country (France) without starting: does the map change? Does the New World get covered with TI at that moment? Then a New World country: does the map change (is the Old World covered)?
  4b. In the country list: with the rule on Hidden are New World countries gone from it, is there a chip *RNW probe: outside America* that you can untick, and does the list become whole when you do or when the rule is Shown?

- **What I read afterwards** (read only): `debug.log` for the five `RNW probe:` lines and `error.log` for lines about the rule, the hooks or `debug_log`; nothing else.
- **What the answers decide:**
  - Probe lines present and the rule listed → rules are a real in-game channel: the visibility option becomes a rule of every generated world, and `has_game_rule` drives what the start does (for example revealing the New World to the player at the start, with `discover_area` over the generated areas).
  - The lobby covers the New World with TI once a country is chosen (or at once) → TI at selection is the game's own and needs nothing more from the mod; the remaining piece is only that New World countries cannot be chosen.
  - The lobby shows everything and covers nothing, whoever is clicked → the lobby has no viewing country, and a mod has found no data that gives it one (C127). Then the choices are: thin the list of countries with the filter (if it works) and rely on TI from the first day of the campaign; or ask for a change to an engine or interface file (the lobby's GUI, or the TI shader through its define), which the product rule forbids without the owner's explicit approval.
  - The country list obeys the filter → New World countries can be left out of the list by default, with the rule as the switch on the new-game screen and the chip as a second one. The map can still select a country by a click on a visible location.
  - The probe lines are missing but the rule is listed → rules show but scripts do not read them as thought; I would find the working hook before building on it.
