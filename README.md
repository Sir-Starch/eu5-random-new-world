# EU5 Random New World

Research and bootstrap repository for a future Europa Universalis V Random New World generator. The goal is genuinely generated geography and civilizations while retaining a historical Old World.

**Status (2026-10-13):** feasibility research in progress. No generator or in-game validation is claimed. The project targets the current EU5 1.4 beta family, with installed build and interface compatibility to be verified for each patch.

See [research findings](docs/research/findings.md), [feasibility](docs/feasibility.md), and the [architecture handoff](docs/handoff/opus-5.5.md). Development commands will be documented here once the stack is selected.
